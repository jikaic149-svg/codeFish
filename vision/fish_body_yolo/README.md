# 黑色机器鱼 YOLO 检测模型

当前 [best.pt](best.pt) 为优化后交付模型，检测黑色机器鱼全身，包括鱼鳍和尾部；类别固定为 `0: fish`。约 6.3 MB，输入 960，默认置信度 0.25。

训练只使用用户指定的 `SAKANA/屏幕录制 2026-10-18 115851.mp4`，没有加入其他机器鱼视频。源视频 SHA256 为 `b47664d4d0621adf8bee890f2f2c314cf3337d166360612fb579a0e4e9a778d1`；模型选择、权重 SHA256 和评估值随 `selection.json`、`metrics.json` 保存。完整训练目录仅保留在本机 `runs/yolov8n-960-robust-v3/`。

## 优化与结果

保留已确认的紧框和时间划分：训练原帧 60 张、验证 12 张、测试 13 张，集合间隔 7.5 秒。原训练帧派生出 180 张光照、背景模糊、背景纹理增强图及 23 张背景负样本，共 263 张训练视图。派生图没有改动鱼体框坐标，验证、测试原帧未参与训练。

本轮使用原模型微调 58 轮，最佳模型来自验证集第 23 轮。额外训练的 v4 在较强灰度／负样本增强下出现退化，保留在实验目录，未部署；选择记录见 `selection.json`。

| 指标 | 原模型 | 当前模型 |
|---|---:|---:|
| 13 张测试帧 Recall，Ultralytics 原生评估 | 76.9% | 100.0% |
| 测试 mAP50 | 95.2% | 99.5% |
| 测试 mAP50-95 | 53.4% | 60.2% |
| 全视频无检测帧，固定 conf=0.25 | 75 | 4 |
| 最长连续无检测 | 1.17 秒 | 0.13 秒 |

受控压力测试使用相同的 25 张验证／测试原帧，经固定变换后在 conf=0.25、IoU≥0.5 下匹配：

| 条件 | 原模型正确检出 | 当前模型正确检出 |
|---|---:|---:|
| 原画面 | 21/25 | 25/25 |
| 变暗 | 20/25 | 24/25 |
| 变亮 | 23/25 | 25/25 |
| 低对比度 | 19/25 | 22/25 |
| 灰度 | 16/25 | 22/25 |
| 偏色 | 1/25 | 23/25 |
| 背景模糊 | 21/25 | 25/25 |
| 背景变色 | 5/25 | 25/25 |

背景变色压力测试仍有 9 个额外误报；原画面有 1 个额外误报。25 张背景负样本上的误报由 8 个降至 0 个。完整结果及框坐标保存在本机 `comparison.json`。这些变换测试不能代替不同水池、相机和光照的实拍验证，反复使用的同一小型留出集也不代表无偏泛化指标。

## 使用

上位机默认加载本目录 `best.pt`，视觉运行时同时使用短时光流测量保持位置连续；航向完全来自标定后的 IMU yaw，不从位移或光流方向推算。

```python
from ultralytics import YOLO
model = YOLO(r'C:\Users\rlyoulo\Desktop\SAKANA\RobotFish-ESP-IDF\vision\fish_body_yolo\best.pt')
results = model.predict(source='你的视频.mp4', imgsz=960, conf=0.25, device=0, save=True)
```

复现脚本在 `SAKANA/fish_body_yolo/scripts/`。环境：Python 3.13.14、Ultralytics 8.4.118、PyTorch 2.11.0+cu128、OpenCV 5.0.0、RTX 5060 Laptop GPU。只交付 `.pt`，未转换模型格式。
