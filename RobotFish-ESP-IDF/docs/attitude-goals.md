# 水下机器鱼角度闭环控制目标

更新日期：2026-10-24。

当前阶段：只接入 yaw 闭环测试。pitch、roll 保持预览，不向执行器输出纠偏。以下指标是待验证目标，不代表本鱼已经达到。

## 1. 目标依据：别人已经完成的实物实验

| 实物研究 | 实际完成的效果 | 对本工程的意义 |
| --- | --- | --- |
| Mo 等，线驱机器鱼，Biomimetics 2024 | 水槽中完成 30°、45°、60°固定航向跟踪；连续航向参考变化率为 5°/s、20°/s、30°/s，最快一档存在滞后 | 结构与推进方式较接近，作为 yaw 功能与动作效果的主要参考 |
| Wang 等，BlueROV2 Heavy，AISMC 研究，表 IV 的 Task #1 | 同一零角度保持实验中：普通 PID 的 pitch／roll／yaw RMSE 约为 1.89°／0.85°／1.90°；AISMC 约为 0.34°／0.28°／1.60° | 提供可核对的角度误差量级；八推进器平台与本鱼不同，不直接复制参数或承诺相同效果 |
| 同上，Task #3 | 连续俯仰变化实验中，AISMC 的 yaw RMSE 约为 1.00° | 作为进一步提高航向精度的参考；不能把不同任务的最优值拼成一个三轴实验结果 |

机器鱼论文的图 8 仍有明显姿态振荡，未报告统一的角度 RMSE、超调量或稳定时间。不能据此编造“误差小于 1°、一秒收敛”等指标。

NTNU 水下四足机器人也完成了三轴实机姿态控制，但实验限制深度，且表 1 指标经过 3 秒居中滑动平均；可参考动作与控制结构，不直接当作本鱼自由游动的精度基准。

## 2. 第一阶段：yaw 航向保持

在水中固定推进工况下，开启开关后保持当前航向，尾舵和双螺旋桨使用混合驱动共同纠偏。

| 项目 | 本鱼的阶段目标 | 指标性质 |
| --- | --- | --- |
| 保持段 yaw RMSE | ≤ 2° | 从别人普通 PID 实测约 1.90°选取的工程验收目标，尚未在本鱼验证 |
| 运动稳定性 | 不发散、不出现持续自激振荡 | 工程验收要求 |
| 控制输出 | 保留现有限幅与限速，记录饱和占比，检查是否长期打满 | 工程验收要求，不把命令百分比当成实测力矩 |
| 手动接管 | 人工转向优先，松开后保持新航向；停止后不恢复旧目标 | 当前已确定的控制行为 |
| 角度边界 | 正确通过 0°及 ±180°，不误判整圈误差 | 软件与水测验证要求 |

每组相同参数至少做 3 次独立水测，分别报告结果和最差一次，不只挑最好的一段。重复次数属于本工程测试约定，不是论文结论。

- [ ] 固定一个推进工况，完成闭环关闭时的基线记录。
- [ ] 同工况开启 yaw 闭环，记录原始角度、滤波角度、参考角度和执行器命令。
- [ ] 计算保持段 RMSE，并报告最大绝对误差、偏差和波动情况。
- [ ] 达到 yaw RMSE ≤ 2°，同时通过手动接管、停止及边界验证。

## 3. 第二阶段：自主角度跟踪

对标机器鱼论文已经完成的任务，逐项验证：

- [ ] 水中自主跟踪 30°、45°、60°航向指令。
- [ ] 跟踪 5°/s 连续变化的航向参考。
- [ ] 第一档稳定后，再验证 20°/s；30°/s作为探索工况，允许如实记录执行器带来的滞后。

`2.7.0-heading-target` 已开放 Wi-Fi `heading_target` 和 LoRa 代码26目标输入，PC可把鱼头零位下的目标转换为S3局部IMU航向。S3执行同一个本地角度PID，阶跃和连续目标的软件链路已验证；上述水中实测项目仍未完成，人工转向后松开锁定也不算自主角度阶跃跟踪通过。

上升时间、超调量、稳定时间均需记录，但本阶段不凭空设置统一秒数。先根据本鱼实测确定误差带、保持时长及合理动态指标，再写入验收条件。

## 4. 后续三轴与精度提升

- pitch、roll 完成算法预览后，仍保持实际输出关闭；接入前须实测水平零点、胸鳍作用方向及控制能力。
- 分别测试 pitch、roll，单轴稳定后再做三轴耦合测试。
- 三轴静态保持可先选 pitch／roll RMSE ≤ 1°、yaw RMSE ≤ 2°作为后续工程目标；这是参考 BlueROV2 实测量级选取的目标，不是本鱼已验证能力。
- yaw 的进一步参考档位为约 1° RMSE，依据是上述 Task #3 的实机结果；不将其表述为全工况或全球最优。

本文件不构成自动开启 pitch／roll 的指令。实际接入仍需另行确认。

## 5. 统一测试与统计口径

所有用于控制效果验收的数据必须来自水中实测。记录推进模式、前进指令、测试时长、电池状态、是否受约束、天线位置和外界扰动，使不同轮次可以比较。地面测试用于验证方向、开关及通信流程。

目标角度与测量角度使用同一坐标定义：用户侧左转 yaw 增大，上浮 pitch 减小，roll 增大为向右翻滚。

```text
e[k] = wrap180(目标角度[k] - 测量角度[k])
RMSE = sqrt(mean(e[k]^2))
```

- 稳态保持段与转向过渡段分别统计，标明取段起止时间。
- 原始 IMU 输出和软件滤波后的误差分别报告，保留原始曲线，避免滤波掩盖真实摆动。
- 依设备时间和实际新样本统计，不把缓存重复读取当作新增测量。
- 单独报告有效样本率、通信缺口及最长中断；缺失数据不插值成“成功控制”。
- 主动断开必须标注，不混入非主动故障统计；也不将其作为一次连续保持试验通过的证据。
- RMSE 小于某数值不意味着每一瞬间误差都小于该数值。
