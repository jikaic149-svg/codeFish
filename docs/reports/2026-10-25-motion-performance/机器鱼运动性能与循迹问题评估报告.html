总体判断

机器鱼已经具备低速自主游动、有效转弯和持续闭环循迹能力；当前仍属于可用的实验平台。受测航段横向平均误差约10–12 cm，急弯存在明显航向滞后，还不足以认定为已完成精确曲线跟踪整定的系统。

主要短板是路径几何与动态转向能力不匹配、尾偏置与摆动共享关节行程，以及减速时尾拍同步变弱。新版修复了摆幅挤占转向偏置的问题；新日志没有再出现此前的长时间断控。上述判断不等于整机运动包线或水动力模型已完成标定。

1.1 哪些量不能混为一谈

“偏置百分数”是控制输入，不是水动力攻角。在新增静态组，40／60／80／100%对应单关节名义偏置9.6／14.4／19.2／24°；真正相对局部来流的攻角还受体轴侧滑、关节组合、摆动速度和局部流场影响，当前未直接测量。尾角遥测是驱动指令；不能用它证明机械舵机已准确达到该角度。

后段速度、末窗稳定候选与稳态性能不同。旧kinematics.csv:v_steady取估计运动开始后、到松开前的后60%时间窗口中位值，没有稳态检验。本报告改称“后段速度”。在线summary的非空steady_speed_mps也只是末约2秒连续样本的低波动判据；早期32段仅21段通过，不足以证明长时间稳态或最大能力。

转弯半径分两种。旧radius_est_m用后段速度除以另一时间窗口的角率，且角率混用体轴与轨迹几何来源；fit_r_m是圆拟合半径。新静态试验的turn_radius_m来自驱动阶段位置点圆拟合，本文优先采用，并同时列拟合残差、覆盖角与拒绝原因。

1.2 循迹统计规则

PC仅纳入tracking=true样本。FISH按启动代次和uptime_ms去重，再限制在每个活动PC区间首末时间内；中断区间另列。统计按样本加权，分位数线性插值。16:53记录的PC约1.62 Hz，其余约3.33 Hz，因此跨轮饱和比例和误差分布只能作描述性比较。

严格统一窗口后，最新FISH为558条；此前单轮分析的561条包含首条PC前的3条鱼端记录，故尾偏饱和22.22%与此前22.1%是边界口径差异。16:53统一窗口为188条，与此前187／210条也有窗口和去重差异；本报告跨轮表统一采用同一算法。

所有事件时间以UTC或metadata为准。新增静态目录名“17点”对应metadata UTC“16点”，不得仅凭文件夹名称排序不同试验。四点标定、检测框中心P、相机延迟估计和视觉噪声仍会影响绝对精度。[D1–D4]

2.2 尾拍记录说明了什么

早期纯尾指令频率随驱动20／30／40%约为0.67／0.82／0.95 Hz，两节命令相位差约60°；混合约72°，后节幅度通常约为前节0.9。它们表明生成器确实在输出有相位差的周期命令，不是水中尾鳍位移或推进波效率的实测。时间滞后应由相位差除以360°和频率计算，不能将不同频率一律写成0.25秒。

纯尾30%直航的一段命令拟合半幅约10.24°、拟合R²约0.744，不支持所有段“摆幅严格单调”。当前新版由速度环同时降低尾驱动与桨推，最新日志全活动窗口尾拍频率中位0.44 Hz、名义半幅约10.41°；急弯阶段可进一步降到0.29 Hz／7.24°。强摆幅倍率不能保证所有工况都有大摆动。

2.3 直航与姿态稳定性的评价

部分长航段体轴偏航漂移较小，说明具备保持直行的基础；但旧表纯桨20%两段体轴角率约3.09和4.95°/s，不能推广“所有模式直航漂移均小于1°/s”。目前缺少重复同档直航、流场记录、完整姿态安装标定和外部姿态真值，报告不对全平台的航向漂移上限、抗流能力、俯仰／横滚稳定性或续航作定量保证。

因此，这组数据能够证明尾偏置的转向作用和低速转弯能力；不能直接证明左右能力差异，也不能替代当前摆尾增益1.5模式的转向包线。不建议用这4个右转点拟合一个看似高R²的公式直接上线。[D2]

3.2 旧“混合80%”与差动能力需要重新解释

既有分析把|tail_bias| + |prop_diff|作为合成输入：所谓“混合80%”实际为尾偏40%＋桨差动40%，同时尾驱动和桨共同推进各20%；不是尾偏80%。这些混合段角率约20～23°/s、几何半径约0.89～1.10 m，属于四个输入共同作用，不能分离尾偏、尾拍或差动的净贡献。

纯尾40%偏置样本给出约8.7～11.0°/s角率，但来源一部分为轨迹几何、一部分为体轴；相应几何半径约0.604／0.489 m，而v/ω估算约0.504／0.495 m，两者不得混用。先前“偏置解释86%”“速度无关”受输入混杂、角率来源和小样本影响，不作为控制规律。

纯差动20～30%样本转向弱且不稳定，40%也存在明显不对称：一段左向命令约−0.816°/s，右向约9.908°/s，测量方法还不同；不能简化为“40%都能7～10°/s”或“差动永远无效”。共同推进命令为0时，纯差动仍可产生约0.105～0.244 m/s后段平移，说明正反桨百分数均值为0并不保证实际推力抵消。当前循迹差动设0有实验依据，但后续辅助差动需单独标定。[D1]

4.2 控制中断的状态已经改善，但结论有窗口边界

14:52日志在UTC14:51:27.823出现imu_unavailable，14:51:32.220恢复，状态空档4.397秒。恢复首帧航向误差−107.61°、横偏−0.574 m；紧接下一帧变为+52.21°，相邻环绕变化为159.82°。“107°”应指恢复首帧误差，不能与相邻跳变量混称。此前源码／日志排查指向PC反馈与路径重建问题，而不是单凭体轴180°翻转就能解释。

16:09、16:53、17:45保留活动窗口均未观察到新的暂停，终止原因均为arrived。最新目标发送9.82 Hz、RTT中位89.13 ms、ACK年龄最大124 ms；运行中零推进仅2/219条，仍在tracking，属于收油而非停发。16:53的pause_count=5是早于该航段的历史值，没有在本段增加。

视觉帧龄约31 ms只是程序所报告的帧年龄；源码另使用0.30秒估计相机延迟，并有视觉速度窗口与IMU滤波。网络RTT与帧龄健康不等于整条感知—动作延迟已经测准。通信连续性改善也不能消除物理转弯滞后。

4.3 最新急弯：偏置修好了，剩下的是动态与分配约束

在17:44:49～58 UTC，PC航向绝对误差中位42.22°，实际速度0.043 m/s、目标约0.0405 m/s；尾偏中位100%、有效偏置24°，而尾驱动只有3.73%、频率0.29 Hz、半摆幅7.24°。连续满偏约8.052秒。速度基本降到了要求，航向却仍明显滞后；此时问题不能通过单独改速度定义解释。

2.7.7作用可直接核验：124条满转向样本中122条保住24°偏置，其余两条为偏置过渡。这修复了2.7.6中大摆幅同比压小偏置的确定性冲突。不过单关节可用行程±32°，24°偏置只剩±8°摆动余量；指令前节在58～73.89°间往复，仍然在摆，并非静态卡死。

6. 更一致的数学描述与最小补测方案

6.1 把轨迹曲率、体轴偏航率和执行器输入分开

χ = ψ + β
κ轨迹 = χ̇ / U = (r + β̇) / U
R轨迹 = U / |r + β̇|　（U > 0）

这里U是平面运动速度，ψ为鱼体航向，χ为运动方向，β为侧滑角，r=ψ̇。只有侧滑近似不变、时间窗口一致时，才能用R≈U/|r|。因此“速度不影响转向”与“只看偏置即可决定半径”都过强；低速和转弯期间运动方向估计又更容易被定位噪声影响。这些是运动学关系，不是本鱼已辨识的水动力系数。

一般水动力模型区分惯性、耦合项、阻尼和执行器产生的广义力；控制分配则在执行器位置／速率等约束内实现期望力或运动。这里采用这一分层原则，不直接套用船舶参数。参见Fossen海洋航行器模型及Fossen与Johansen的控制分配综述。

待辨识的低阶模型：
U̇ = F(U, q桨, A, f, δ, …)
τr · ṙ + r = G(U, q桨, A, f, δ, …)
前节约束：|δ| + A ≤ 32°；当前名义 |δ| ≤ 24°

q桨为共同桨指令，A／f为实际分配后的尾拍半幅／频率，δ为名义尾偏。F、G、τr尚未识别。上述一阶形式只是可检验的简化候选；若残差、左右方向或配方变化显著，就应采用分段表或更合适的模型，而非强行拟合一个常数。

沿轨速度投影有助于描述纵横耦合，但不会自动增加可实现角速度。按曲率限速应检验所需运动方向变化率U·|κ|与该工况可实现转向率及其响应时间，还要考虑收油所需提前距离。常见平方根曲率限速需要有依据的横向加速度上限；当前没有足够数据把该上限或τ定为可靠常数。
