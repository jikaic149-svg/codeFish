# 动力标定测试

## 当前入口与配方

使用2.7.7-steering-priority和workstation-36-steering-priority。测试页顶部直接点击“摆尾＋双桨测试 · 当前循迹配方”或“静态尾角测试 · 不摆尾对照”，无需先展开混合菜单。可直接打开 `/dynamics.html#swim` 或 `/dynamics.html#static`；点击入口只加载参数，不发送动作。

摆尾模式尾驱动与共同推进相同（初值10+10）、差动0，固件目标摆幅增益1.5；静态对照尾驱动0、差动0。2.7.7在非baseline混合标定中采用与循迹相同的偏置优先策略：先保留尾攻角，剩余关节行程用于摆动。两者均可只换尾偏0/40/60/80/100%，X/Z阶跃不改变原先尾摆和共同推进。静态尾角实验是对照，不再被当作实际循迹配方。新增9段静态实验与恢复摆尾的实验应分组分析，原始桌面数据保持不变。

## 当前循迹配方的低速补测

33版测试页新增“混合 → 循迹静态尾角”：尾摆和桨差动固定为0，共同推进由操作者调整后保持，尾偏可独立选择0／40／60／80／100%。这是参数加载，不自动启动动作。先让实际速度落入约0.04–0.08m/s，再比较偏置；不要同时改变尾摆和差动。每段仍人工决定时长，不强制15秒。

E2阶跃：选左／右转及尾偏0，开始本段并持续按住动作，等速度稳定后按X施加±60%尾偏、按Z回0。两个键只改变尾偏，保留双桨共同推进；命令未确认时不排队下一阶跃，松开动作仍全停。可人工重复并通过事件／原始CSV拟合响应。同段参数变化会标记mixed_settings，不冒充单一配方稳态值。既有尾角缓变和舵机动态会进入测得的整机响应；驱动写入角不是实际舵机角传感器值，不能将全部延迟都称为纯水动力τ。

用户的yaw_map.py把abs(tail_bias)+abs(prop_diff)作为bias_mag，因此混合80%不是实际尾偏80%；其总体回归不能直接外推当前单独67%静态尾偏。纯尾子集尾摆与偏置共同变化，也未分离偏置因果效应。原报告和数据保持只读，未把该回归、25%死区或τ=0.3–0.8s写入控制器。

建议以实际独立输入(T,δ)记录(U,r,β)与动态过程，先辨识低阶等效响应，再反算前馈和可行曲率。概念上可用τr·dr/dt+r=f(U,T,δ)，但系数和适用区间须由开环数据确定；平面建模依据参见[Fossen水动力模型](https://www.fossen.biz/html/marineCraftModel.html)。E3在自由游动中不能同时独立固定速度又改变推进：应固定偏置、分档推进并记录实际速度，或者另有可控水流／拖曳条件。速度降低并不天然保证舵效足够，需要联合检验v·|κ|与该工况可达到的偏航率。

使用固件 `2.7.2-drive-calibration` 与上位机 `workstation-31-dynamics-vision`。重新运行 `upper/start.cmd` 后，点击左侧“动力标定测试”。测试页内直接显示实时视觉，可启动画面、框选鱼和点选鱼头；已有运行中的视觉直接复用。

场地固定长3.0m、宽1.6m，相机高度2.67m。已保存的同一相机、同一分辨率四角自动复用，并按固定长宽计算米制变换，不要求每段重新标定。相机移动或从未标定时才需重新选四角。高度只作为场景信息，不能替代四点变换。点选鱼头后自动建立当前朝向0°并同步IMU参考，无需单独置零。

每段操作：让鱼静止并确认箭头正确 → “鱼已静止，开始本段” → 按住动作 → 松开全停 → 等滑行／余转结束 → 完成本段。动作时长由操作者决定；下一组只加载参数。鱼尾、双桨和混合模式支持独立尾摆、尾偏置、共同推进和差动。固定给定期间暂停反馈接管，原PID数值保留；闭环验证须随后明确启动。旧混合规则作为单独基线，可包含转向补尾推，不与独立配方混为一组。

新固件的自动航向模式取消转向补尾摆：前进量归零时尾摆幅度及频率归零，保留尾偏置与双桨差动。物理速度、漂移和余转须通过实测确定。

桌面实际路径下的 `RobotFish-Dynamics` 保存每段独立目录，名称包含时间、驱动模式、动作、四个给定值和唯一标识。开始新段清空本段内存显示，已保存文件保留。原始视觉／鱼端JSONL、样本CSV、事件JSONL持续刷盘；完成后生成metadata、summary与总表。松开后继续记录；请求、回执、遥测输出归零及视觉估计起动分别保留。保存失败可重试，未保存段禁止覆盖。

记录包含相机接收／估计采样时间、PC单调时间与UTC、鱼端uptime、位置、世界方向及原始／滤波IMU、实际桨尾指令、分配量、PID分项和各次操作。采集按源约10Hz，原始快照落盘；界面仅显示最近样本。一秒位移速度用于复核；短弧不足时不输出可靠半径，同段多配方不输出单一配方稳态标定值。命令回执不代表已产生机械运动，执行器遥测是写入指令而非位置／推力传感器值。
