## 2026-10-23：上位机本地诊断与遥测/网页刷新优化

用户要求添加不显示的本地日志，排查 IMU 刷新慢、数据过期及网页卡顿，并明确要求保持网络连接。本轮只修改上位机代码与相关测试/文档；未断开或切换电脑网络，未重启现有上位机服务，未连接实鱼、打开真实串口、发送实鱼指令或烧录固件。启动修订更新为 workstation-7-realtime，启动器仅检测旧服务，不终止它；后台改动需下次启动本版服务后生效。

源码确认 JY61P UART 为 115200/8N1，MCU 原轮询为 10 ms，而上位机原每 250 ms 才读取遥测，每次设备 HTTP 请求都关闭连接。网页每次又重复应用设备设置、重建隐藏日志及数据表。波特率、传感器输出频率和网页刷新率相互独立，IMU 回传走 Wi-Fi，不经过 LoRa 空口；本轮没有将串口配置改成更高波特率，也没有改变固件任务、协议、失联保护、IMU 坐标或采样配置。

新增 upper/diagnostics.py，使用标准库有界队列和异步日志线程，写 upper/logs/workstation.jsonl，单文件约 5 MiB，保留 3 份轮转历史；队列满时丢弃新诊断，避免阻塞控制。日志不进入网页抽屉或控制台，记录请求元数据/耗时、每秒 IMU 字节与合法帧增量、数据年龄、错误计数、路由、安全状态、浏览器异常与长任务。未记录请求正文、密码、Cookie 或控制会话；日志目录加入 .gitignore。浏览器诊断经现有 Host/Origin/token 校验的 POST /api/diagnostics 批量提交。

upper/device_client.py 将遥测与控制锁分离，75 ms 内共享最新原始快照，遥测复用独立 HTTP 连接，异常后关闭该连接且不立即重试。控制会话或已接受序号变化会绕过缓存，避免显示旧模式/目标。upper/robotfish.py 归一化时保守计入 HTTP 完整往返时间和缓存年龄；原始数据不就地修改，500 ms 有效阈值保留。upper/robot.js 在 RobotFish 前台按目标 100 ms 连续调度，隐藏窗口约 1 s；合并到浏览器绘制帧，缓存设备界面配置、仅在文本变化时更新，独立更新 IMU 过期显示。upper/workstation.js 合并图表鼠标/尺寸重绘，避免重复调整画布和重建图例/同一批数据表，隐藏日志抽屉不构造日志行；原手动记录仍为 1 Hz。涉及 server.py、backend.js、launch.py、README 和新增回归文件，既有其他未提交修改保留。
