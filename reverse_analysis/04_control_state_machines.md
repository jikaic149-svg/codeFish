# 控制与状态机

## 驱动模式

固件内部模式值由分支、响应文本和日志共同确认：

| 值 | 模式 | 主要推进方式 |
| ---: | --- | --- |
| 1 | BIONIC | 尾部周期摆动 |
| 2 | PROP | ESC 螺旋桨推进 |
| 3 | HYBRID | 尾部与 ESC 同时工作 |

模式切换会清除前进、后退和转向标志，将尾部与 ESC 目标恢复安全中位，然后更新状态灯。网页发送 `var=mode&val=0` 时按模式循环，不把前端传来的 0 当作实际模式值。

## CPG 与输出整形

`control_tick` 位于 `0x42003708`。已直接确认的控制骨架是：

1. 没有前进、后退或转向标志时，将两路尾部目标设为 86.0，并继续执行尾部/ESC 的渐进归中；
2. 仿生或混合推进时，根据毫秒时间、功率百分比、模式常量和正弦/相位运算产生两路尾部目标；
3. 螺旋桨或混合推进时，根据方向和功率生成 ESC 油门/转向目标；
4. 所有角度先限制为 0～180，再由更新函数逐步逼近并写入 Servo。

相关标定常量可从 helper 指令直接读出：

- 尾部中位：86.0°；
- 两个功率百分比开机均为 100；
- 普通模式尾摆幅值比例 50，HYBRID 为 58；
- 一组尾部转向修正比例普通为 12，HYBRID 为 8；
- ESC 中心基准为 88；
- 正向 ESC 增量为 `36 * power / 100`，HYBRID 为 `44 * power / 100`；
- 反向 ESC 减量为 `34 * power / 100`，HYBRID 为 `42 * power / 100`；
- 尾部渐进步长常量普通为 6.0，HYBRID 为 10.0。

正弦生成段还包含 52/66、1.7/2.45、0.35/0.42 和 0.9 等浮点常量。它们与时间归一化、相位和转向混合共同使用；由于镜像已去符号，变量原名和完整数学表达式只能高可信近似，不能宣称恢复为原始 C++ 源码。

## 人工控制的互锁

`/control` 收到有效动作时先调用 `on_control_command`：

- 若正在失联自动上浮，清除 failsafe 标志，打印“检测到新控制指令”，恢复当前模式状态灯；
- 人工动作会取消正在运行的 Demo；
- Partner 脚本与直接驾驶存在停止/抢占调用，避免两套逻辑同时持有推进输出；
- `stop` 清运动标志并把尾部、ESC 恢复中位；
- 每一步 Partner 动作开始前也先清推进和水泵，防止前一步状态泄漏。

## 失联保护

看门狗函数 `0x42003d60` 的条件和时间均由立即数直接确认：

- 每约 500 ms 执行一次链路检查；
- 开机前 15,000 ms 不触发；
- SoftAP 客户端数大于 0，或 STA 状态为已连接，均视为在线；
- 两条链路都断开后开始计时；连续超过 3,000 ms 才触发；
- 触发函数 `0x42003d14` 具有一次性保护，不会重复进入。

触发后的动作是：

1. 清除运动标志并将尾部、ESC 归中；
2. 胸鳍俯仰设置为 45°，形成头部上扬/自由上浮姿态；
3. 水泵关闭；
4. RGB 状态灯设为橙色并在保护期间维持提示；
5. Demo 和 Partner 启动请求被拒绝或停止。

任何新的有效人工控制会退出保护，因此这里是“可由操作者接管”的安全状态，而不是只能重启解除的锁死状态。

## Demo 状态机

`request_demo` 返回三种文本：`DEMO_STARTED`、`DEMO_CANCELLED` 或 `DEMO_BLOCKED_FAILSAFE`。若当前模式不适合演示，它会自动切到 BIONIC，然后进入非阻塞状态机：

| 状态 | 后端持续时间 | 动作 |
| --- | ---: | --- |
| 1 | 4000 ms | Forward，pitch 90° |
| 2 | 3500 ms | Dive，pitch 135° |
| 3 | 4000 ms | Surface，停止推进并 pitch 45° |
| 4 | 1200 ms | Stop，pitch 90° |

后端总动作时间约 12,700 ms。前端按钮计时为 `4000 + 3500 + 4000 + 1200 + 400 = 13,100 ms`，最后 400 ms 是 UI 复位余量，不是额外后端动作阶段。重复点击 Demo 会取消当前演示；人工控制也会取消演示。

## Partner JSON 约束

解析器位于 `0x420070c8` 附近。字符串、数值比较和错误路径共同确认：

| 约束 | 范围 |
| --- | --- |
| 请求体 | 1～3500 字节 |
| `repeat` | 1～10 |
| 步数 | 1～32 |
| 普通 `duration_ms` | 0～30000 ms |
| 运动动作时长 | 至少 100 ms |
| `pump_on` 时长 | 100～10000 ms |
| `pitch` 时长 | 至少 100 ms |
| `angle` | 45～135° |
| `power` | 20～70 |
| `strength` | 10～70 |
| 脚本总时长 | 1～300000 ms，包含 repeat |

支持动作：

```text
mode_bionic mode_prop mode_hybrid
forward backward left right stop
pitch pump_on pump_off
```

解析器拒绝未知顶层字段、未知步骤字段、非整数参数、空 steps、缺少 action、名称过长或包含不支持字符以及 JSON 后的额外内容。

## Partner 运行引擎

持久化命名空间为 `partner_cfg`。保存前完整校验 JSON；启动时再次确认已经加载有效脚本且不处于 failsafe。`partnerTick` 每次只检查当前步骤截止时间并推进索引，不在步骤持续期间阻塞：

- 当前步骤结束后先安全停止该动作；
- 步骤索引递增；
- 一轮结束后递增 pass，未达到 repeat 时回到第 1 步；
- 全部完成后清 running 并打印完成日志；
- 运行中发现 failsafe 会立即安全停止。

固件内置默认脚本为：

```json
{
  "name": "Partner demo",
  "repeat": 1,
  "steps": [
    {"action": "mode_bionic"},
    {"action": "forward", "power": 55, "duration_ms": 3000},
    {"action": "stop", "duration_ms": 800},
    {"action": "left", "power": 45, "strength": 40, "duration_ms": 1200},
    {"action": "pitch", "angle": 110, "duration_ms": 1200},
    {"action": "stop", "duration_ms": 500}
  ]
}
```

若 NVS 中脚本过大或校验失败，固件打印原因并回退到这个内置脚本。
